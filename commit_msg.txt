feat(analysis): implementar pipeline completo de análisis IA para PaperLab WebAR

Backend FastAPI con arquitectura modular monolith que recibe una imagen
de un dibujo a mano, la procesa con un LLM multimodal vía OpenRouter,
y devuelve un JSON validado con los parámetros del experimento.

Incluye:
- Módulo analysis completo con 4 skills (physics, circuit, flowchart,
  math_geo) usando discriminated unions de Pydantic v2
- Catálogo consolidado de 19 tipos de ejercicio según la rúbrica oficial
  (6 física + 6 circuitos + 2 diagramas + 5 matemáticas)
- Adaptador de OpenRouter con LangChain y structured output
- Puerto LLMClient abstracto para permitir cambiar de proveedor sin
  tocar el pipeline
- Validación determinística de schema, confianza y rangos físicos
- Preproceso mínimo de imagen (orientación EXIF + resize 1024px)
- Endpoint POST /analyze/{skill} con retry y feedback al LLM
- Endpoints auxiliares GET /health y GET /skills
- Scaffolds vacíos para módulos futuros (sessions, catalog, users,
  history)
- Configuración con pydantic-settings y .env
- README con instrucciones de setup y ejecución

El LLM extrae únicamente los inputs del experimento. Los cálculos
físicos y la simulación son responsabilidad del motor determinístico
(otro equipo), respetando la separación IA y simulador definida en
la arquitectura del proyecto.
